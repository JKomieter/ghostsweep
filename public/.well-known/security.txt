# 1. Subresource Integrity (SRI) - FALSE POSITIVE
# ------------------------------------------------
# Finding: Scripts lack integrity attributes
# Status: False Positive / Not Applicable
#
# Explanation:
# - All JavaScript is served via Next.js from our domain (_next/static/)
# - Next.js uses content-addressed filenames (e.g., main-a1b2c3d4.js)
# - The hash in the filename IS the integrity mechanism
# - When content changes, the filename hash changes automatically
# - This is equivalent to and more reliable than SRI attributes
#
# External Resources:
# - Vercel Analytics: Self-hosted by Vercel (same-origin, no SRI needed)
# - Vercel Speed Insights: Self-hosted by Vercel (same-origin, no SRI needed)
# - Google Fonts (Inter): Optimized and self-hosted by Next.js automatically
# - No third-party CDN scripts are loaded
#
# Additional Protections:
# - Content Security Policy restricts script sources to trusted domains
# - Strict-Transport-Security enforces HTTPS-only connections
# - All resources served over HTTPS with valid certificates
#
# References:
# - https://nextjs.org/docs/architecture/nextjs-compiler
# - https://web.dev/articles/content-addressed-resources
